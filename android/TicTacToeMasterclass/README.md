# TicTacToeMasterclass

An Android Tic-Tac-Toe app built with Kotlin and Jetpack Compose. Play locally with two players or challenge the device, which uses Minimax. The app detects wins and draws, prevents invalid moves, and lets players restart the game. The initial “Hello World” screen was the first stage of the project.

## Prerequisites

- JDK 17
- Android Studio with Android SDK 37 installed

## Build and Test

Run these commands from the project root:

```sh
./gradlew test
./gradlew assembleDebug
```

Open this folder in Android Studio to run the app on an emulator or Android device.
